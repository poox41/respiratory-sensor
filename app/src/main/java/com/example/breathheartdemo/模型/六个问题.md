## 四、完整处理流程（单epoch，30秒）

```
原始信号（50Hz）
    ↓
【阶段1】预处理（保存前）
    ↓
1. BCG滤波：Butterworth 4阶低通，1Hz，零相位
2. 呼吸滤波：Butterworth 4阶低通，1Hz，零相位
3. 重采样：BCG 50Hz→100Hz，呼吸 50Hz→25Hz
    ↓
【阶段2】特征提取前处理
    ↓
4. NaN清理：x = np.nan_to_num(x, nan=np.nanmedian(x))
5. 去趋势：x = x - np.nanmedian(x)
    ↓
【阶段3】特征提取
    ↓
6. R峰检测：
   - 内部自动做：Butterworth 3阶带通，5-20Hz，零相位
   - 平方信号后用find_peaks检测
7. 提取57维特征
    ↓
【阶段4】推理
    ↓
8. 归一化：x_norm = (x - mean) / std
9. ONNX推理：input=(1, 11, 57), output=(1, 2)
10. 决策：睡眠概率≥0.205 → 睡眠
```

## 五、滤波函数实现（必须完全一致）

### 5.1 Butterworth带通滤波

```python
from scipy.signal import butter, filtfilt

def butter_bandpass_filter(x, fs, low, high, order):
    """
    Butterworth带通滤波（零相位双向滤波）
    
    Args:
        x: 输入信号
        fs: 采样率
        low: 低频截止频率 (Hz)
        high: 高频截止频率 (Hz)
        order: 滤波器阶数
    
    Returns:
        滤波后的信号
    """
    nyquist = 0.5 * fs
    low_norm = max(low / nyquist, 1e-3)
    high_norm = min(high / nyquist, 0.95)
    
    if not (0 < low_norm < high_norm < 1):
        return x
    
    b, a = butter(order, [low_norm, high_norm], btype="band")
    y = filtfilt(b, a, x)
    
    return y
```

### 5.2 Butterworth低通滤波

```python
def butter_lowpass_filter(x, fs, cutoff, order):
    """
    Butterworth低通滤波（零相位双向滤波）
    
    Args:
        x: 输入信号
        fs: 采样率
        cutoff: 截止频率 (Hz)
        order: 滤波器阶数
    
    Returns:        滤波后的信号
    """
    nyquist = 0.5 * fs
    cutoff_norm = min(cutoff / nyquist, 0.95)
    
    if not (0 < cutoff_norm < 1):
        return x
    
    b, a = butter(order, cutoff_norm, btype="low")
    y = filtfilt(b, a, x)
    
    return y
```

## 六、R峰检测函数（必须完全一致）

```python
from scipy.signal import find_peaks

def detect_ecg_peaks(ecg, fs):
    """
    R峰检测（与训练代码完全一致）
    
    Args:
        ecg: ECG/BCG信号
        fs: 采样率
    
    Returns:
        R峰索引数组
    """
    if len(ecg) < int(fs * 3):
        return np.array([], dtype=int)
    
    # 1. NaN清理 + 去趋势
    x = ecg.astype(np.float64)
    x = np.nan_to_num(x, nan=np.nanmedian(x))
    x = x - np.nanmedian(x)
    
    # 2. 内部自动做滤波：5-20Hz带通，order=3
    try:
        xf = butter_bandpass_filter(x, fs, low=5.0, high=20.0, order=3)
    except Exception:
        xf = x
    
    # 3. 平方信号
    y = xf ** 2
    
    # 4. 质量检查
    if not np.isfinite(y).all() or np.nanstd(y) < 1e-12:
        return np.array([], dtype=int)
    
    # 5. 峰值检测
    min_dist = max(1, int(fs * 0.45))  # 最小距离：0.45秒
    p90 = np.nanpercentile(y, 90)
    p50 = np.nanpercentile(y, 50)
    prominence = max((p90 - p50) * 0.35, np.nanstd(y) * 0.25, 1e-12)
    
    peaks, _ = find_peaks(
        y,
        distance=min_dist,
        prominence=prominence,
    )
    
    return peaks.astype(int)
```

## 七、ONNX推理接口

### 7.1 输入输出规格

| 项 | 规格 |
|----|------|
| **输入名** | `"input"` |
| **输入形状** | `(batch_size, seq_len, feature_dim)` = `(1, 11, 57)` |
| **输出名** | `"output"` |
| **输出形状** | `(batch_size, 2)` = `(1, 2)` |
| **输出含义** | `[清醒logit, 睡眠logit]` |

### 7.2 完整推理代码（Python示例）

```python
import onnxruntime as ort
import numpy as np
import json

# 1. 加载ONNX模型
session = ort.InferenceSession("sleep_bcg_v1.onnx")

# 2. 加载配置文件
with open("sleep_bcg_v1.json", "r", encoding="utf-8") as f:
    config = json.load(f)

mean = np.array(config["mean"], dtype=np.float32)
std = np.array(config["std"], dtype=np.float32)
threshold = config["threshold"]
seq_len = config["seq_len"]
feature_dim = config["feature_dim"]

# 3. 准备输入（11个epoch的57维特征）
# features_batch: (1, 11, 57)
features_batch = np.random.randn(1, seq_len, feature_dim).astype(np.float32)

# 4. 归一化
features_norm = (features_batch - mean) / std

# 5. 处理可能的异常（NaN/Inf/std=0）
features_norm = np.nan_to_num(features_norm, nan=0.0, posinf=0.0, neginf=0.0)
safe_std = np.where(std == 0, 1.0, std)
features_norm = (features_batch - mean) / safe_std

# 6. ONNX推理
input_name = session.get_inputs()[0].name
output_name = session.get_outputs()[0].name
logits = session.run([output_name], {input_name: features_norm})[0]

# 7. Softmax计算概率
exp_logits = np.exp(logits - np.max(logits, axis=1, keepdims=True))
prob = exp_logits / np.sum(exp_logits, axis=1, keepdims=True)
prob_sleep = prob[0, 1]

# 8. 决策
state = 1 if prob_sleep >= threshold else 0
state_text = "睡眠" if state == 1 else "清醒"

print(f"预测状态: {state_text}")
print(f"睡眠概率: {prob_sleep:.4f}")
```

## 十、关键注意事项（绝对不能搞错！）

1. **BCG不做ECG的0.5-40Hz滤波！**
   - BCG和呼吸都只做**1Hz低通**
   - 0.5-40Hz是ECG预处理专用

2. **R峰检测的5-20Hz滤波是内部自动做的！**
   - 不需要在外部单独调用
   - detect_ecg_peaks函数内部会自动处理

3. **必须先滤波再重采样！**
   - 顺序不能反
   - 否则会混叠，准确率暴跌

4. **特征顺序绝对不能错！**
   - 严格按照57维特征列表的顺序
   - 顺序错了模型会完全失效

5. **归一化必须用BCG专用的mean/std！**
   - 在sleep_bcg_v1.json中
   - 不要用其他模型的参数

6. **NaN/Inf/std=0的处理必须完整！**
   - 按本文档"七.5"的代码处理
   - 不能遗漏
